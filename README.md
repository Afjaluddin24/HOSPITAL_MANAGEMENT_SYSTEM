🏥 Hospital Management System – Web Application

A full-stack Hospital Management System web application developed using ASP.NET Core Web API for the backend and React.js with Bootstrap 5 for the frontend.
This project focuses on role-based dashboards, secure authentication, and a clean UI structure for real-world hospital operations.

🚀 Technologies Used

🔧 Backend

ASP.NET Core Web API
Entity Framework Core
SQL Server
JWT Authentication
OTP-based Login (Email)

🎨 Frontend

React.js
Bootstrap 5
Axios
JWT Token Handling
